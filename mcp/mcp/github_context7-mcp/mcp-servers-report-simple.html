    Use cases

    Watch out

    Impact = our estimate.

    If you want to…

    Good fit / poor fit

    Use it for

    • Repos, files, issues, PRs on GitHub
    • Letting AI read or act on GitHub
    • Automating a GitHub routine

    Not for

    • Library docs (use Context7)
    • Files only on your computer
    • Read-only work with a full-power token

    In code

    async with GitHubMCPClient() as gh:
    await gh.list_tools()          # menu first
    r = await gh.call_tool("get_file_contents", {
        "owner": "aashwini1010", "repo": "my-repo", "path": "hello.py"})
    print(r.content[1].resource.text)
